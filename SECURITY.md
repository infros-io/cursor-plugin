# Security

This repository contains only the Cursor Marketplace listing for InfrOS: a manifest, the MCP server address, a logo and this documentation. It runs no code. The InfrOS MCP server and the InfrOS platform are developed in a private repository.

If you believe you have found a security issue in InfrOS, the MCP server, or this listing, please email **support@infros.io**. Do not open a public issue. We will acknowledge your report and keep you informed as we address it.
